# Notification-System

Designed and implemented a Distributed Notification System using C++ and Object-Oriented Programming (OOP) principles to manage and deliver notifications reliably across multiple channels. The system supports email, SMS, and push notifications through a modular and extensible architecture. Implemented core components such as Notification, NotificationService, NotificationFactory, NotificationChannel, and NotificationRepository to ensure separation of concerns and maintainability. Applied design patterns, including Factory and Strategy, to simplify notification creation and enable dynamic selection of delivery channels. Designed mechanisms for asynchronous processing, retry handling, and failure management to improve reliability and prevent notification loss. The architecture supports adding new notification channels without modifying existing business logic. Focused on scalability, extensibility, and fault tolerance while maintaining clean code and reusable components. This project demonstrates practical applications of Low-Level Design (LLD), SOLID principles, design patterns, and distributed systems concepts for building maintainable and reliable notification infrastructure.
